# Fantasy Rules Research

Defining our own rules now that SportsDeck is not offering F1 fantasy for 2026.

## Folder Structure

- **`decisions/`** — Source of truth. If it's here, it's decided: format, scoring, pricing, design goals.
- **`reference/`** — Support material consulted while deciding: glossaries, F1 context, lessons learned, dynamic pricing research.
- **`competitors/`** — Per-platform profiles for active F1 fantasy games.
- **`archive/`** — Superseded research and earlier pricing model explorations. Only open when explicitly needed.
