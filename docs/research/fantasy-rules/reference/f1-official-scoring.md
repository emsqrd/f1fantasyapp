# Official F1 Fantasy Scoring Rules

Source: official F1 Fantasy game (fantasy.formula1.com). Captured 2026-03-14.

Points are awarded/deducted based on driver/constructor performance at the Grand Prix. Classifications are based on FIA and Formula 1 decisions.

---

## Qualifying

### Drivers

| Position     | Points |
| ------------ | ------ |
| P1 (pole)    | +10    |
| P2           | +9     |
| P3           | +8     |
| P4           | +7     |
| P5           | +6     |
| P6           | +5     |
| P7           | +4     |
| P8           | +3     |
| P9           | +2     |
| P10          | +1     |
| P11–P20      | 0      |
| NC / DSQ / no time set | −5 |

Drivers who do not set a time in Q1 receive −5, including inactive drivers.

### Constructors

Constructors score the **combined total of both drivers' qualifying points**, plus:

| Achievement                  | Points |
| ---------------------------- | ------ |
| Neither driver reaches Q2    | −1     |
| One driver reaches Q2        | +1     |
| Both drivers reach Q2        | +3     |
| One driver reaches Q3        | +5     |
| Both drivers reach Q3        | +10    |
| Disqualified driver          | −5 per driver |

## Sprint

_Applies on sprint weekends only._

### Drivers

| Position | Points |
| -------- | ------ |
| P1       | +8     |
| P2       | +7     |
| P3       | +6     |
| P4       | +5     |
| P5       | +4     |
| P6       | +3     |
| P7       | +2     |
| P8       | +1     |
| P9–P20   | 0      |

| Event                        | Points                  |
| ---------------------------- | ----------------------- |
| Positions gained             | +1 per position         |
| Positions lost               | −1 per position         |
| Overtakes made               | +1 per overtake         |
| Fastest lap                  | +5                      |
| DNF / DSQ / Not classified   | −10                     |

DNF/Not Classified penalties apply to all drivers, including those classed as inactive or not in the final starting grid.

Positions gained/lost are based on starting vs finishing position. Cars starting from the pit lane are considered to start from a position relative to the last car on the grid.

Overtakes are valid when a driver legally passes another on track, where the driver passed was not entering/in the pit lane, suffering a car failure, or going unreasonably slow.

### Constructors

Constructors score the **combined total of both drivers' sprint points**, plus:

| Event                      | Points        |
| -------------------------- | ------------- |
| Disqualified driver        | −10 per driver |

## Race

### Drivers

| Position | Points |
| -------- | ------ |
| P1       | +25    |
| P2       | +18    |
| P3       | +15    |
| P4       | +12    |
| P5       | +10    |
| P6       | +8     |
| P7       | +6     |
| P8       | +4     |
| P9       | +2     |
| P10      | +1     |
| P11–P20  | 0      |

| Event                        | Points                  |
| ---------------------------- | ----------------------- |
| Positions gained             | +1 per position         |
| Positions lost               | −1 per position |
| Overtakes made               | +1 per overtake         |
| Fastest lap                  | +10                     |
| Driver of the Day            | +10 (driver only)       |
| DNF / DSQ / Not classified   | −20                     |

DNF/Not Classified penalties apply to all drivers, including those classed as inactive or not in the final starting grid.

Positions gained/lost are based on starting vs finishing position, not qualifying result. Unclassified drivers do not have positions lost calculated — they receive the −20 penalty instead.

Driver of the Day is the official F1 Driver of the Day award result.

### Constructors

Constructors score the **combined total of both drivers' race points**, excluding Driver of the Day, plus:

**Pit stop scoring:**

| Pit stop time   | Points |
| --------------- | ------ |
| Over 3.0s       | 0      |
| 2.50 – 2.99s    | +2     |
| 2.20 – 2.49s    | +5     |
| 2.00 – 2.19s    | +10    |
| Under 2.0s      | +20    |
| Fastest pit stop of race | +5 |

New world record time bonus: +15 (current record: 1.8s set by McLaren in Qatar 2023).

| Event               | Points        |
| ------------------- | ------------- |
| Disqualified driver | −20 per driver |
